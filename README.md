# Shroom Shuffle

An original single-file browser minigame. Each round names one safe mushroom; every other one sinks into the water. Jump the gaps, stun rivals, and be the last one afloat.

**Controls:** WASD or arrows to run, Space to jump, X (or Shift / J) to ground-pound in mid-air, R to restart.

Everything here is original: procedural canvas art and code, with no third-party assets, characters, names or audio.
